# E-Commerce Website – UI/UX Design

## Project Overview
A modern e-commerce website UI/UX design created using Figma. The project focuses on creating a visually appealing interface with clear product presentation, intuitive navigation, and a user-friendly shopping experience.

## Project Objectives
- Design a clean and modern e-commerce interface.
- Create an organised and visually consistent layout.
- Improve navigation and overall usability.
- Design an engaging shopping experience for users.

## Tools Used
- Figma – UI Design and Interactive Prototyping

## Design Focus
- User Interface (UI) Design
- User Experience (UX)
- Visual Hierarchy
- Typography and Colour Selection
- Layout and Navigation
- Interactive Prototyping
